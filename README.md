# D0 →KSππ Asymmetry Analysis

This package contains the code to analyse the effects of the trigger and reconstruction efficiencies on the measurement of mixing and CP asymmetry in D0→KSππ decays.

## Preparation of the environment

The environment can be prepared by running the following command in the terminal:

```bash
uv sync
```

This will install all the required dependencies in a virtual environment placed in the `.venv` directory. Please note that the `uv` command is provided by the [`uv`](https://github.com/astral-sh/uv) package.
